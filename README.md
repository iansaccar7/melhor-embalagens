# Melhor Embalagens & Utilidades

Página de catálogo com busca, filtros e lista de pedido enviada pelo WhatsApp. O layout é responsivo e usa as cores e imagens da loja em uma apresentação inspirada na linguagem visual da Apple.

## Visualizar

Abra `dist/index.html` no navegador. O site é estático e não exige instalação ou build.

Versão publicada: https://melhor-embalagens-utilidades.clerencristinasaccar.chatgpt.site

Os itens marcados como não verificados dependem de confirmação de disponibilidade e preço pela loja.
