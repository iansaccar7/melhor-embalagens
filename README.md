# Melhor Embalagens & Utilidades

Página de catálogo com busca, filtros e lista de pedido enviada pelo WhatsApp. O layout escuro e responsivo usa as cores e imagens da loja, com seções amplas e cards de categorias.

## Visualizar

Abra `docs/index.html` no navegador. O site é estático e não exige instalação ou build.

Versão publicada: https://melhor-embalagens-utilidades.clerencristinasaccar.chatgpt.site

Os itens marcados como não verificados dependem de confirmação de disponibilidade e preço pela loja.
